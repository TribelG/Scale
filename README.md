# Scale — блокаут уровня

Учебный 3D-проект на Unity: прототип уровня из трёх комнат с препятствиями, разрывом пола и возвышенностью. Геометрия собрана из стандартных объектов Unity.

## Требования

- Unity Hub
- Unity Editor **6000.3.27f2 (Unity 6.3 LTS)**
- Пакеты устанавливаются автоматически по файлам в `Packages`.

## Как открыть

1. Скачайте репозиторий или клонируйте его.
2. В Unity Hub выберите **Add → Add project from disk** и укажите корень проекта, содержащий `Assets`, `Packages` и `ProjectSettings`.
3. Откройте проект редактором 6000.3.27f2 и дождитесь импорта.
4. Откройте `Assets/Scenes/Blockout.unity`.
5. Нажмите **Play** для просмотра через игровую камеру.

## Управление камерой

Компонент `Assets/Scripts/Camera.cs` обеспечивает свободный полёт:

| Действие | Управление |
| --- | --- |
| Движение | WASD |
| Поворот | Мышь |
| Подъём / спуск | Space / Ctrl |
| Ускорение | Shift |
| Виды по комнатам и общий обзор | F1–F4 |
| Освободить курсор | Esc |
| Вернуть управление | Щелчок левой кнопкой в окне Game |

Камера проходит через стены: столкновения и гравитация для неё не реализованы. Скорость и чувствительность настраиваются в Inspector.

## Структура

- `Assets/Scenes` — сцены проекта.
- `Assets/Scripts` — скрипты управления.
- `Assets/BlockoutMaterials` — материалы блокаута.
- `Assets/Settings` — настройки рендера.
- `Packages` — зависимости Unity.
- `ProjectSettings` — настройки проекта.

Это блокаут для проверки масштаба и планировки. Игровая логика кнопок, открывания дверей и контрольных точек требует отдельной реализации.

## Перенос и Git

Храните папки `Assets`, `Packages`, `ProjectSettings` и все файлы `.meta`. Они сохраняют связи сцен, скриптов и материалов.

Папки `Library`, `Temp`, `Obj`, `Logs` и `UserSettings` исключены из Git. Unity создаст необходимые локальные данные при открытии проекта; первый импорт может занять несколько минут.
